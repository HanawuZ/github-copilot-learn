# Hello World .NET Application

This is a simple Hello World console application built with .NET 7.0.

## Prerequisites

- .NET 7.0 SDK or later

## Building the Application

To build the application, you can:
1. Use VS Code's build task (Ctrl+Shift+B)
2. Run `dotnet build` in the terminal

## Running the Application

To run the application, you can:
1. Use VS Code's run task
2. Run `dotnet run` in the terminal

The application will print "Hello, World!" to the console.
